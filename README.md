# 🎮 Dash Thru

**Dash Thru** is a 3D motion-controlled multiplayer racing game developed with Unity as part of the SimPlay platform.

Players use their smartphones as controllers to launch marbles, navigate obstacles, collect points, and race to the finish line.

## 🕹️ Features
- Local multiplayer for up to 2 players
- Smartphone tilt controls using accelerometer sensors
- Charge-based launching mechanics
- Color-based point collection
- Randomized level arrangements
- Real-time client-server communication

## 🛠️ Tech Stack
**Unity** • **C#** • **Mirror Networking** • **WebGL** • **NGINX**

This project marked my first professional experience in game development, providing hands-on experience with Unity, multiplayer networking, and client-server architecture.

## 🎮 Demo & Platform
- **Platform:** Windows (.exe)
- **Demo:** Not available online

The game runs as a Windows executable and requires a local client-server setup, with smartphones connected as controllers. Therefore, a standalone browser demo is not available.
